# 앱 화면 구성 (App Screen Layouts)

## 📱 Main Screen (MainActivity)

### 화면 구성
```
┌─────────────────────────────────────────────────────────┐
│  ← 목적지 알림                                    ⋮      │
├─────────────────────────────────────────────────────────┤
│                                                         │
│                   🗺️ Google Maps                       │
│                                                         │
│              📍 현재 위치 (파란색 점)                     │
│                                                         │
│                                                         │
│              📌 목적지 마커 (빨간색)                      │
│                                                         │
│                                                         │
│                                                         │
│                                                         │
├─────────────────────────────────────────────────────────┤
│  목적지: 37.5665, 126.9780                              │
│  (지도를 클릭하여 목적지를 설정하세요)                     │
│                                                         │
│  ┌─────────────────┐  ┌─────────────────┐             │
│  │  🚀 추적 시작    │  │  ⏹️ 추적 중지   │             │
│  └─────────────────┘  └─────────────────┘             │
│                                                         │
│  ┌─────────────────┐  ┌─────────────────┐             │
│  │  ❌ 목적지 해제  │  │  ⚙️ 설정       │             │
│  └─────────────────┘  └─────────────────┘             │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 주요 기능
1. **Google Maps**: 전체 화면의 대부분을 차지
2. **현재 위치**: 파란색 점으로 표시
3. **목적지 마커**: 지도 터치 시 표시
4. **정보 패널**: 하단에 목적지 좌표와 제어 버튼들

### 버튼 상태
- 초기 상태: "추적 시작" 비활성화
- 목적지 설정 후: "추적 시작" 활성화
- 추적 중: "추적 시작" 비활성화, "추적 중지" 활성화

2. **알림 설정**
   - 음량: 0-100% 슬라이더
   - 진동: On/Off 스위치
   - 소리: On/Off 스위치

3. **앱 정보**
   - 버전 정보
   - 사용 방법 안내

## 📱 Responsive Design

### Landscape Mode
지도가 더 넓게 표시되고, 하단 제어 패널이 2열로 배치됩니다.

### Tablet Support
큰 화면에서는 지도와 설정을 동시에 표시하는 2-pane 레이아웃으로 최적화 가능합니다.

### Accessibility
- 텍스트 크기 조정 지원
- 고대비 모드 지원
- TalkBack 스크린 리더 지원
- 터치 타겟 크기: 최소 48dp
